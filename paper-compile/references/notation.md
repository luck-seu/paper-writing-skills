# Template: notation.md (machine view)

Notation table for writing consistency — **as used in the paper**, not
as declared: the macro sources (content-classified — see
`references/file_map.md`; no file name is hardcoded) define the
global supply, the view records what the prose actually consumes.
The macro sources are a shared library inherited across papers, so
unused declarations are expected and are NOT listed (author ruling
2026-10-25) — the actionable signal is the duplicate section below:
you hand-typed what a declared macro already prints.

**Verdict: script-perfect.** The scan (math-mode control sequences),
counting, first-section lookup, and the duplicate check (string
equality between a hand-typed token and a declared expansion) are
mechanical. What a symbol *denotes*, and whether the notation is the
right choice, is judgment and lives with the author (and the target
repo's style guide when present), not here.

```markdown
# Notation (as used in the paper)

| Notation | Form | Uses | First used in |
|---|---|---|---|
| `\mathcal{X}` | macro `\X` | 12 | 2_prelim |
| `\theta` | hand-typed | 3 | 2_prelim |
| `\card{\A}` | macro `\card` | 2 | 3_method |

## Hand-typed duplicates of declared macros

- `\mathcal{B}` hand-typed 4x; macro `\B` already declares it -- use
  the macro
```

Rows are in first-appearance order. "hand-typed" rows with no
declared macro are the notation-without-a-macro signal: if the symbol
recurs, the fix is a macro in a macro source, not more hand-typing.

## Source & regeneration

- Math segments: inline `$...$`, `\(...\)`, one-line `\[...\]`, and
  the interior of display environments (`equation`, `align`,
  `gather`, `eqnarray`, `displaymath`, `math`, `*` variants) over
  the prose files (every discovered `.tex` the file map does not
  classify as a macro source — `references/file_map.md`);
  comment-stripped.
- Tokens: every control sequence plus one simple braced argument
  (`\mathcal{X}`, `\card{\A}`); structural commands (begin/end,
  cite/ref/label, text, frac, spacing) are skipped by an ignore
  list.
- Macro mapping: every macro-source file (roles classified by
  content — see `references/file_map.md`; no file name is
  hardcoded), comment lines excluded; last live definition wins.
- Not notation, never tabled (author ruling 2026-11-02): standard
  math symbols (operators, relations, arrows, dots, delimiters,
  log-like names, named constants — the fixed `STANDARD_SYMBOLS`
  list in `scripts/views/notation.py`); a font switch applied to two or
  more letters (`\mathit{type}` — prose emphasis); and `\kw{...}`
  carrier macros (reserved for a future terminology view). A
  hand-typed standard symbol still reaches the duplicate section
  when a macro declares it.

Known scan limits (documented in the view footer): bare letters
(variables with no control sequence) are not tokenized; a token
swallows its own argument; one-line `\[...\]` and begin/end lines
inside a display environment are approximations. Prose is read
through `macromap.read_content`: comment-stripped and
swallow-blanked — `\name{arg}` of a macro whose live body never
references its argument (`\eat`-style) is removed before scanning,
one braced argument per call, so eaten content is not usage.

`python3 scripts/compile.py notation`.
